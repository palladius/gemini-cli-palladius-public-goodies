# Article Workspace Directory

This directory contains the workspace for the article. Below is a map of the files and what each does:

- [ARTICLE.md](ARTICLE.md): The main draft of the article containing metadata frontmatter and content.
- [PLAN.md](PLAN.md): The execution checklist followed by the AI during implementation.
- [01-CREATION.md](01-CREATION.md): The initial checklist completed by the author when starting the article.
- [50-WORKING-DOC.md](50-WORKING-DOC.md): The author's timeline log of design decisions, thoughts, and intent.
- [90-COMPLETION-LIST.md](90-COMPLETION-LIST.md): The completion checklist verifying content quality and asset completeness.
- [99-SIGNOFF-TODO.md](99-SIGNOFF-TODO.md): The final reviewer approvals and assistant audit signatures.
- [TODOs.md](TODOs.md): A personalized task list for the author's custom actions.
- [SOURCES.md](SOURCES.md): Public and private references and bibliographical links.
- [AI_REASONING.md](AI_REASONING.md): The workspace where the AI records drafts, ideas, and logic.
- [HUMAN_REASONING.md](HUMAN_REASONING.md): The workspace where the human author records drafts, ideas, and logic.
- [HERO_IMAGE_PROMPT.md](HERO_IMAGE_PROMPT.md): The text prompt used to generate the article's hero image.
