# Pre-Creation Checklist

Before creating a new article folder structure, the agent or user MUST verify and confirm the following:

## 1. Core Inputs
- [ ] **Author**: Name and surname (default to Riccardo Carlesso).
- [ ] **Title**: A clear working title.
- [ ] **Bug**: A Buganizer ID (e.g. `b/123456`). If none exists, ask the user to create one, or default to `b/TODO`.
- [ ] **CTA**: A Call-to-Action URL.
- [ ] **Intent**: A brief description of the value and target audience (MUST be at least 500 characters).
- [ ] **Platform**: The target publishing platform (e.g., Medium, Personal Blog, Google Official Blog, Dev.to).
- [ ] **PublishDate**: Target publication date (defaults to 7 days from now).

## 2. Environment Validation
- [ ] **Articles Directory**: Verify that `/usr/local/google/home/ricc/git/ricclife-with-gemini-pvt/work/articles` exists on the local filesystem.
