# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-30
### Added
- Initial version of the take-screenshot skill.
- Cross-platform screenshot utility for macOS and Linux (Wayland XDG Desktop Portal).
- Basic Markdown documentation in `SKILL.md`.
- Added `--non-interactive` flag to bypass user prompt on supported systems.
